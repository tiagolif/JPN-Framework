Fundamento · revisão interna

Método JPN

Para aprender a estruturar uma tarefa antes de delegá-la à IA.

Organiza contexto, objetivo, restrições, fatos, lacunas, critérios e estado final em três camadas: Jornada, Precisão e Narrativa.

  • Use quando: o problema ainda precisa ser bem definido.
  • Entrega central: método, exemplos, prática e referência rápida.
  • Não é: garantia de resposta correta ou substituto de validação especializada.

Ferramenta · revisão interna

JPN Prompt Builder

Para transformar uma ideia em uma instrução estruturada e revisável.

Conduz o preenchimento do JPN, mantém lacunas visíveis, organiza presets e compila o prompt sem exigir uma API externa para funcionar localmente.

  • Use quando: você quer apoio guiado para montar o pedido.
  • Entrega central: interface, presets, espaços locais e fluxo de revisão.
  • Estado: QA físico/contextual em celular ainda pendente.

Biblioteca · revisão interna

JPN Prompt Pack

Para começar tarefas recorrentes a partir de estruturas reutilizáveis.

Reúne 18 templates PP-* organizados pelo framework, com campos que continuam exigindo adaptação ao contexto real de cada tarefa.

  • Use quando: a tarefa se repete e um bom ponto de partida economiza preparação.
  • Entrega central: biblioteca de prompts e referência de seleção.
  • Não é: coleção de respostas prontas ou atalho para omitir contexto.

  • Entrega central: playbooks, workbook de implementação e materiais de revisão.

Rotas de uso canônicas

Comece pelo menor produto suficiente e avance só quando houver necessidade.

As rotas abaixo espelham o contrato interno de uso do portfólio. Elas descrevem continuidade de trabalho, não bundles, descontos, ofertas ou obrigação de usar todos os produtos.

Aprender

Método JPN → Prompt Pack → Prompt Builder

Use quando: a pessoa ainda precisa dominar a lógica JPN antes de acelerar a execução.

Pare quando: o objetivo imediato já puder ser resolvido com clareza usando somente o Método JPN.

Executar

Prompt Pack → Prompt Builder

Use quando: a necessidade já é conhecida e um template reutilizável reduz trabalho de estruturação.

Pare quando: o template escolhido já puder ser adaptado e utilizado sem ferramenta adicional.

Operar

JPN Business → Prompt Pack → Prompt Builder → Gestão Fácil

Use quando: a pequena empresa precisa transformar uma necessidade recorrente em playbook, prompt e acompanhamento operacional.

Pare quando: o playbook e os materiais necessários já forem suficientes para executar a rotina escolhida.

Gestão

Gestão Fácil → JPN Business

Use quando: a necessidade principal é organizar clientes, vendas, tarefas, estoque e controle gerencial básico.

Pare quando: a rotina operacional estiver organizada sem necessidade de playbook adicional.

Conjunto · apenas arquitetural

JPN Pro Kit

Use quando: somente quando o kit estiver efetivamente congelado e validado como release final.

Estado atual: enquanto houver dependências abertas, esta rota permanece apenas arquitetural e não comercial.

Antes de apresentar

O estado do produto faz parte da mensagem.

Este catálogo autoriza publicação ou venda?

Não. Ele é um material interno de composição e revisão. Não autoriza publicação, anúncio, preço, checkout, captação de leads ou venda.

O produto mais completo deve ser indicado primeiro?

Não. A regra é escolher o menor produto que resolva a necessidade atual. O Pro Kit não é recomendação automática por ser mais abrangente.

Os estados de revisão podem ser ignorados em uma apresentação?

Não. Enquanto houver dependências abertas, o produto permanece em revisão interna e não deve ser apresentado como release-ready ou disponível publicamente.
