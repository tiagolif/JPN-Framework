Recursos

Recuperação

Autosave defensivo

Snapshots locais reduzem perda acidental entre salvamentos explícitos sem criar conta ou sincronização em nuvem.

Privacidade

Sem conta e sem envio automático.

Os recursos locais usam o navegador. A ferramenta não executa automaticamente conteúdo importado, não envia projetos para servidor externo e não substitui a revisão humana do prompt compilado.

FAQ

O que o Builder faz — e o que não faz.

O Builder executa a tarefa final?

Não. Ele organiza e compila a instrução para revisão; a execução final acontece na ferramenta de IA escolhida pelo usuário.

Precisa de API paga?

O fluxo principal foi preparado para funcionar localmente sem exigir API externa.

Os projetos são sincronizados em nuvem?

Não. O modelo atual mantém projetos, presets e recuperação no navegador, com exportação e importação manuais.
