# JPN — Registro interno de conversa comercial v1

Status: modelo interno. Não é CRM, proposta, contrato, pedido, checkout ou autorização de venda.

## Objetivo

Registrar somente o contexto necessário para qualificar uma necessidade, indicar o produto JPN proporcional ao problema e preparar um próximo passo sem inventar preço, urgência, disponibilidade ou resultado.

Use este modelo com dados fictícios em treinamento e QA. Em uso real futuro, aplique apenas a política de dados e privacidade formalmente aprovada para o canal correspondente.

## 5. Claims e condições

Antes de enviar qualquer material, confirmar:

- [ ] nenhum resultado foi garantido;
- [ ] nenhum percentual de ganho, economia ou melhoria foi inventado;
- [ ] nenhum preço, desconto, bônus ou condição foi inventado;
- [ ] nenhuma data de disponibilidade foi presumida;
- [ ] nenhum candidato interno foi apresentado como produto final;
- [ ] nenhuma afirmação como “100% privado”, “sem erros” ou “funciona em qualquer IA” foi feita sem evidência correspondente;
- [ ] nenhuma urgência ou escassez artificial foi usada.
