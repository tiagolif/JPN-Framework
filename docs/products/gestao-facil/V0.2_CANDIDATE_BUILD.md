# JPN Gestão Fácil — v0.2 candidata

Status: `candidate / local generation verified / cross-app QA pending`

## Objetivo

Evoluir o workbook reconstruído v0.1 para uma base mais pronta para pequenas empresas, alinhada ao `DATA_MODEL_v0.2.md`, sem promover compatibilidade, release ou uso financeiro real antes de evidência física.

## Estrutura gerada

A candidata possui as oito abas canônicas:

1. `Leia-me`
2. `Dashboard`
3. `Clientes`
4. `Vendas`
5. `Tarefas`
6. `Estoque`
7. `Financeiro`
8. `Listas`

## Melhorias incorporadas

- Dashboard operacional com KPIs derivados das abas de origem;
- gráfico simples de situação das vendas;
- tabelas estruturadas para Clientes, Vendas, Tarefas, Estoque e Financeiro;
- validações de dados ligadas à aba `Listas`;
- fórmula de `Valor total` baseada em `Quantidade × Valor unitário`;
- fórmula de `Reposição?` com estados `REPOR` e `OK`;
- formatação condicional para destacar `REPOR`;
- congelamento de cabeçalhos nas abas operacionais;
- datas e valores com formatação apropriada;
- exemplos apenas fictícios nas abas operacionais;
- aba Financeiro sem linhas monetárias de exemplo preenchidas por padrão;
- avisos de limites na aba `Leia-me` e no Dashboard.

## Guardrails preservados

- `REPOR` é somente alerta operacional e não autoriza compra;
- a aba Financeiro é gerencial e não substitui contabilidade, banco, obrigação fiscal ou auditoria;
- nenhuma senha, token, chave, número completo de cartão ou credencial deve ser registrada;
- exemplos compartilháveis devem usar dados fictícios ou sanitizados;
- nenhum dado financeiro real é necessário para validar a estrutura;
- `GF-QA-10` continua `PENDING` até teste físico em Excel, LibreOffice e Google Sheets;
- esta candidata não implica `release_ready=true`.
