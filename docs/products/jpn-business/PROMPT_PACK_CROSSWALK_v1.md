# JPN Business × JPN Prompt Pack — Crosswalk v1

Estado: **material interno de produto**.

Este mapa torna explícita a conexão entre os 12 playbooks do **JPN Business** e os prompts do **JPN Prompt Pack**. Ele não substitui nenhum dos dois produtos: serve como camada de navegação para quem já sabe qual processo empresarial deseja executar e precisa encontrar rapidamente o prompt de apoio adequado.

## Como usar

1. Escolha o playbook do JPN Business correspondente ao processo real.
2. Consulte o(s) prompt(s) recomendado(s) abaixo.
3. Adapte contexto, restrições, dados disponíveis e saída esperada.
4. Revise o resultado antes de qualquer ação externa.
5. Pare quando o objetivo estiver resolvido; não é necessário percorrer prompts adicionais por padrão.

## Relação com os produtos

O **JPN Business** define o processo e o contexto empresarial. O **JPN Prompt Pack** fornece estruturas reutilizáveis para tarefas específicas dentro desse processo. O **JPN Prompt Builder** pode ser usado depois, quando for útil montar, revisar ou salvar uma versão contextualizada do prompt; ele não é obrigatório para executar o crosswalk.

## Guardrails

- O crosswalk não cria novas condições comerciais nem autoriza ações externas.
- Um prompt recomendado continua sendo um ponto de partida, não execução automática.
- Não presumir dados ausentes, preços, descontos, disponibilidade, prazos ou aprovação interna.
- Publicação, envio, compra, contratação e aceite permanecem ações separadas.
- As referências canônicas estão em `BUSINESS_INDEX.json` e `PROMPT_INDEX.json`.

Nenhuma parte deste material autoriza publicação pública, anúncio, checkout, coleta de pagamento ou aceite legal.
