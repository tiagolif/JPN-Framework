# JPN Pro Kit v1 — Release Notes Internas

Status: `release-candidate-internal`

Base metodológica: JPN Framework `0.3.0-draft`.

## Incluído nesta consolidação

- estrutura de entrega única do Pro Kit;
- guia `LEIA PRIMEIRO` com ordem recomendada de consumo;
- referência explícita às fontes canônicas de Método JPN, Prompt Pack e JPN Business;
- integração prevista com o Prompt Builder que consome o SDK browser oficial;
- mapa de entrega separando fonte, formato final e status real;
- checklist de fechamento técnico, editorial, visual e de pacote;
- template de manifesto com estados explícitos para itens ainda não congelados;
- bloqueio deliberado de preço, checkout, publicação, anúncios, gastos, termos legais e dados financeiros.

## Conteúdo já rastreado no repositório

- Método JPN v1 — draft editorial consolidado;
- JPN Prompt Pack v1 — 18 cartões;
- JPN Business v1 — 12 playbooks;
- índices estruturados Prompt Pack e Business;
- auditoria cruzada e checagem mecânica de consistência;
- Prompt Builder em cadeia técnica de integração com SDK browser.

## Pendência declarada

O JPN Gestão Fácil foi produzido em trabalho anterior, porém seu XLSX e manual não estão versionados no repositório nesta etapa. O Pro Kit não os trata como artefatos presentes até que sejam localizados, revisados e incorporados de forma rastreável.

## Não incluído nesta etapa

- preço;
- condição comercial;
- checkout;
- licença comercial adicional não revisada;
- publicação de site/produto;
- anúncio ou campanha;
- claim quantitativo de desempenho;
- contratação de serviço;
- contas externas novas.

## Critério para próxima promoção

O candidato só deve avançar para `final` depois que os componentes internos atingirem os gates aplicáveis, o Gestão Fácil estiver rastreado, a identidade visual mestre estiver consolidada, PDFs/XLSX finais forem testados e o manifesto final receber hashes dos arquivos congelados.
