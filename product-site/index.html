DEMONSTRAÇÃO

JPN Prompt Builder

Digite uma ideia simples, carregue um preset guiado ou reutilize presets e projetos salvos localmente. A demo usa o SDK oficial do framework para criar e validar o estado JPN e aplica uma camada contextual conservadora ao prompt exibido, preservando lacunas e restrições informadas.

Projetos guardam localmente campos, prompt e rascunho atual para continuidade. Atualizar mantém o mesmo projeto; duplicar cria uma nova cópia independente. Não há conta, nuvem ou sincronização automática.

Recuperação automática local: preparando proteção do rascunho…

Presets só preenchem um ponto de partida editável. Eles não executam IA nem adicionam fatos sobre o seu caso.

Descreva o pedido com suas próprias palavras. Lacunas continuarão explícitas no rascunho.

Campos ausentes continuam explícitos para revisão. A demo não usa um modelo de IA para preencher informações que você não forneceu.

Presets pessoais ficam somente no armazenamento local do navegador. A exportação JSON serve como backup ou transferência manual; nenhum dado é enviado para servidor.

FAQ

Perguntas importantes

Isso é só um prompt grande?

Não. O método separa contexto, objetivo, restrições, critérios, estado final e lacunas para que a solicitação possa ser revisada antes de executar.

Funciona só no ChatGPT?

Não. O núcleo do JPN é independente de provedor e pode orientar prompts para diferentes modelos e agentes.

O JPN garante respostas perfeitas?

Não. O framework organiza a especificação e torna ambiguidades mais visíveis, mas modelos de IA continuam sujeitos a erros.

Preciso saber programar?

Não para usar o método, os packs, os playbooks ou a planilha. O SDK técnico é uma camada opcional.

O Builder inventa o que eu não informar?

A proposta atual é conservadora: lacunas permanecem visíveis para revisão em vez de serem silenciosamente tratadas como fatos.

Onde ficam meus presets e projetos pessoais?

No navegador em que você os salvou. O Builder permite exportar e importar arquivos JSON para backup ou transferência manual, sem sincronização em servidor.

O que acontece se eu fechar a página antes de salvar um projeto?

O Builder mantém um rascunho de recuperação somente neste navegador. Ao voltar, ele restaura os campos disponíveis para revisão; você pode limpar essa recuperação sem apagar projetos ou presets salvos.

O framework já provou superioridade universal?

Não. O projeto inclui infraestrutura de avaliação para testar resultados de forma reproduzível antes de fazer claims quantitativos.
