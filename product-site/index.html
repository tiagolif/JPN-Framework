FAQ

Perguntas importantes

Funciona só no ChatGPT?

Não. O núcleo do JPN é independente de provedor e pode orientar prompts para diferentes modelos e agentes.

O JPN garante respostas perfeitas?

Não. O framework organiza a especificação e reduz ambiguidades, mas modelos de IA continuam sujeitos a erros.

Preciso saber programar?

Não para usar o método, os packs ou o Builder. O SDK técnico é uma camada separada.

O framework é cientificamente validado?

Não reivindicamos validação científica nem superioridade universal. O projeto inclui uma proposta de avaliação justamente para testar resultados em vez de presumir.
